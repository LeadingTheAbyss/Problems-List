| [1900D](https://codeforces.com/contest/1900/problem/D) | 2100 | <details><summary>Show</summary><ul><li>Sort the array. For a triplet `i < j < k`, the two smaller values are `a[i]` and `a[j]`, so we need the sum of `gcd(a[i], a[j])` over all triplets.</li><li>Fix a pair `(i, j)`. Every index `k > j` gives a valid triplet, so this pair contributes `(n - j) * gcd(a[i], a[j])`. Elements between `i` and `j` are handled when they are taken as `j` with an earlier `i`, so nothing is missed or double counted.</li><li>Looping over all pairs is `O(n^2)`, so for each `j` we compute `Σ gcd(a[i], a[j])` over `i < j` faster :<ol><li>Maintain `cnt[x]` = number of already visited elements divisible by `x`.</li><li>Use `gcd(a, b) = Σ φ(d)` over all `d` dividing both `a` and `b`. This avoids overcounting (PIE), since each common divisor is weighted by `φ(d)`.</li><li>For each `a[j]` in sorted order, compute `s = Σ φ(d) * cnt[d]` over the divisors `d` of `a[j]`. Then do `ans += (n - j) * s` and `cnt[d]++` for every divisor `d` of `a[j]`.</li></ol></li><li>Precompute `φ` and the divisor lists up to `max(a)`.</li><li><img width="1520" height="753" alt="image" src="https://github.com/user-attachments/assets/f44f0cc3-5188-40d2-993e-2e0172f02de4" /></li></ul></details> | <details><summary>Show</summary><ul><li>Euler Totient Function</li></ul></details> | [Code](../Codes/1900D.cpp) |
